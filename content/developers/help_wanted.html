Voluntarily Listed

This section lists Bioconductor packages whose maintainers no longer wish to maintainer their package. The package may not currently be failing but the maintainer wishes either a new maintainer transfer or assistance with maintaining the code base. An interested party should contact bioc-devel@r-project.org with the currently listed maintainer in the table also cc'd

Packages with Large Files

This section lists Bioconductor packages that contain large files directly distributed in the code base. Bioconductor is exploring alternative hosting solutions for packages that are more cost-effective and efficient. This prevents packages from having files over 100 MB directly in the package. The files may still be distributed via external sites such as Zenodo or Dryad, and then either hosted in ExperimentHub or AnnotationHub, or provided with a caching mechanism using BiocFileCache. Data can no longer be hosted directly in the package, and Bioconductor does not support git-lfs or hosting on private locations like GitHub or Dropbox; it must be a secure location.

These packages have been warned about the large files in their source code and have yet to reach out for action. If the data remains past the next release, the package will be deprecated. We encourage if you utilize one of these packages to help us locate the maintainer to find alternative solutions or if the maintainer is unreachable to request a transfer of maintainership at bioc-devel@r-project.org
